## 📐 Engineering Principles

My approach to software development is built around a few core principles:

- **Keep It Maintainable:** Write code that other developers can understand and extend.
- **Reuse With Purpose:** Build abstractions when they solve real problems, not just for the sake of abstraction.
- **Respect Existing Logic:** Improve architecture and implementation without introducing unnecessary behavioral changes.
- **Design for Growth:** Consider modularity, scalability, and long-term maintenance from the beginning.
- **Solve the Root Cause:** Investigate underlying issues instead of relying on temporary workarounds.
- **Automate Repetitive Work:** Use tools and reusable workflows to improve productivity and reduce mistakes.
